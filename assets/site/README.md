# Site-wide images and videos

Upload files for the main website here (not client work).

| File name | Used for | Tips |
|---|---|---|
| `showreel.mp4` | Home page background video | Under ~8 MB, 1080p max, no audio needed |
| `showreel.webm` | Same video, optional smaller format | Optional |
| `about-bts.webp` | Behind-the-scenes photo in the About section | Portrait 4:5, e.g. 1200x1500. If missing, the block hides itself |
| `og.jpg` | Preview image when the site is shared (WhatsApp, LinkedIn) | 1200x630 |
| `logo.png` | Your logo, if you want to replace the text logo | Then edit `partials/header.html` |

Use `.webp` or `.jpg` for photos (not PNG, which is huge) and `.mp4` (H.264) for video.
